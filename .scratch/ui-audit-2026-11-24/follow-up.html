Changes

  • Local calendar dates. Task badges and date filters use the browser's local date rather than UTC. The date updates at local midnight and when visibility/focus changes. Scheduling the next midnight through local Date construction handles daylight-saving changes. Server rendering defers browser-timezone-dependent badges until hydration.
  • Keyboard focus. Inline Edit focuses Title; Cancel and Save return focus to Edit. Completing, archiving, or deleting a focused row chooses a surviving task control or a heading. Native dialogs retain their existing protected focus and draft confirmation behavior.
  • Required titles. Create and Edit show “Title (required)” persistently, expose native required semantics, and preserve trimmed-title validation and inline error messages.
  • Earlier task loading. Tasks and Archive load an owner-tagged initial snapshot through their routes. The UI accepts it only for the signed-in identity and resets state when identity changes. Signed-out requests cannot read task snapshots. Private task pages and server-function responses use Cache-Control: private, no-store.
  • Stable refreshes. Refresh keeps existing rows and counts mounted while exposing the busy state. Request ordering prevents older responses from overwriting newer filter results. Commands refresh the latest selected query. Existing error, draft retention, and retry behavior remains.
  • Polish and documentation. Placeholders use the muted-text token at full opacity, correcting the measured approximately 3:1 contrast. Reduced-motion styling targets the app's actual transitions and loading animation. DESIGN.md and its sidecar now match the OKLCH palette, 44px controls, 46px select, responsive grid, and field/focus behavior. The established visual language is preserved.
